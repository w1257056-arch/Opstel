## 📖 О проекте

**Opstel** — это лёгкая и стильная библиотека интерфейсов, написанная
на **Luau** для использования в собственных проектах, плагинах и
обучающих материалах, связанных с Roblox Studio.

Библиотека создавалась как **учебный и творческий проект** с целью:

- изучения принципов построения UI в Roblox (`ScreenGui`, `Frame`, `TweenService`);
- демонстрации современных подходов к дизайну интерфейсов;
- предоставления разработчикам готового набора компонентов
  (кнопки, слайдеры, переключатели, дропдауны и т.д.);
- практики в области анимаций, layout-систем и работы с
  пользовательским вводом.

Проект **не является читом**, **не содержит эксплойтов**,
**не взаимодействует с чужими играми** и **не предназначен для
нарушения правил платформы Roblox или сервиса GitHub**.

## ✨ Возможности

| Компонент       | Описание                                                  |
|-----------------|-----------------------------------------------------------|
| `CreateWindow`  | Главное окно с перетаскиванием, сворачиванием и закрытием |
| `CreateTab`     | Вкладки с иконками и градиентным индикатором              |
| `CreateSection` | Разделители секций                                        |
| `CreateButton`  | Кнопка с ripple-эффектом и hover-анимацией                |
| `CreateToggle`  | iOS-подобный переключатель с пружинкой                    |
| `CreateSlider`  | Слайдер с градиентной заливкой                            |
| `CreateTextBox` | Текстовое поле со сменой цвета бордера при фокусе         |
| `CreateDropdown`| Выпадающий список с плавным раскрытием                    |
| `Window:Notify` | Всплывающие уведомления с прогресс-баром                  |

Также в комплекте:

- 🎨 2 темы: `OpstelDark` и `OpstelLight` (легко добавляются свои);
- 🌈 Градиенты, скругления, мягкие тени;
- 🎬 Spring-анимации (`Enum.EasingStyle.Back`);
- 🛡️ Защита пользовательских callback'ов через `pcall`.

## 🚀 Быстрый старт

```lua
local Opstel = loadstring(game:HttpGet("ССЫЛКА_НА_RAW_OPSTEL.lua"))()

local Window = Opstel:CreateWindow("Моё меню", "OpstelDark")

local Main = Window:CreateTab("Главное", "★")
Main:CreateSection("Утилиты")

Main:CreateButton("Показать уведомление", function()
    Window:Notify("Привет", "Это тестовое уведомление", 3)
end)

Main:CreateToggle("Автоклик", false, function(state)
    print("Автоклик:", state)
end)

Main:CreateSlider("Скорость", 0, 100, 16, function(v)
    print("Скорость:", v)
end)
