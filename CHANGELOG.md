## [1.0.0] — 2025-01-01

### 🎉 Первый публичный релиз

**Opstel** — новая UI-библиотека для Roblox, созданная русскими
разработчиками. Первая версия включает полный набор компонентов,
современный дизайн и поддержку тем.

### ✨ Добавлено

#### Ядро библиотеки
- `Opstel:CreateWindow(title, theme)` — создание главного окна
- Система тем с готовыми `OpstelDark` и `OpstelLight`
- Модульная архитектура на Luau
- Автоматическая подгрузка через `loadstring` + `game:HttpGet`

#### Компоненты интерфейса
- `Window:CreateTab(name, icon)` — вкладки с иконками и градиентным индикатором
- `Tab:CreateSection(name)` — секции с подчёркиванием
- `Tab:CreateButton(text, callback)` — кнопки с ripple-эффектом
- `Tab:CreateToggle(text, default, callback)` — iOS-подобные переключатели
- `Tab:CreateSlider(text, min, max, default, callback)` — слайдеры с градиентной заливкой
- `Tab:CreateTextBox(text, placeholder, callback)` — текстовые поля
- `Tab:CreateDropdown(text, options, callback)` — выпадающие списки
- `Window:Notify(title, text, duration)` — всплывающие уведомления

#### Дизайн и анимации
- **Glass-morphism** — полупрозрачные поверхности с мягкими границами
- **Градиенты** — акценты из двух цветов (фиолетовый → синий)
- **Spring-анимации** — отскок через `Enum.EasingStyle.Back`
- **Ripple-эффект** — волна при нажатии на кнопку
- **Hover-анимации** — плавная смена цвета при наведении
- **Скруглённые углы** — `UICorner` повсюду
- **Мягкие тени** — через `ImageLabel` с `SliceCenter`
- **Анимированный индикатор вкладок** — пружинная полоска слева

#### Управление окном
- Перетаскивание через заголовок (мышь + тач)
- Кнопка сворачивания (анимация сжатия до 52 px)
- Кнопка закрытия (анимация исчезновения)
- Автоматический выбор `CoreGui` или `PlayerGui`

#### Совместимость
- Поддержка ПК (`MouseButton1`, `MouseMovement`)
- Поддержка мобильных (`Touch`-ввод)
- Работа на всех актуальных версиях Roblox
- Защита пользовательских callback'ов через `pcall`
- Не ломает другие UI-скрипты (`ZIndexBehavior = Sibling`)

### 🛡️ Безопасность

- Весь код написан **с нуля** — без сторонних зависимостей
- Нет сетевых запросов, кроме загрузки самого `source.lua`
- Нет телепортации, эксплойтов, обхода защиты
- Проект создан **в добрых намерениях** и для обучения

- Две темы из коробки — свои добавляются вручную

## 📌 Как читать версии

Формат: **`MAJOR.MINOR.PATCH`**

- **MAJOR** — несовместимые изменения API
- **MINOR** — новая функциональность (обратно совместимо)
- **PATCH** — исправления багов (обратно совместимо)
